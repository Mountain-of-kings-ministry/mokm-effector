# Welcome to MOKM Effector

**MOKM Effector** is a powerful, modern, and lightweight timeline-based visual effects editor.

Built with love using **Qt 6** and **QML**, it gives you precise control over animations, layers, keyframes, and effects — perfect for motion graphics, video editing tools, and creative applications.

## Why MOKM Effector?

- **Smooth Timeline Experience** — Fast and responsive even with many layers
- **Real-time Keyframing** — Animate opacity, position, scale, rotation, and more
- **Modern UI** — Clean, dark-themed interface with attention to detail
- **High Performance** — Built natively with Qt for speed and efficiency
- **Extensible** — Easy to add custom effects and properties

## Core Features

- Multi-layer timeline with drag & drop reordering
- Smooth strip moving and resizing with live preview
- Keyframe animation system (position, scale, rotation, opacity, etc.)
- Real-time playback and scrubbing
- Custom theme support
- Export-ready architecture
