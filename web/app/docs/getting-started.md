# Getting Started

Welcome! This guide will help you set up **MOKM Effector** and create your first composition.

## System Requirements

- **Operating System**: Windows 10/11, macOS 13+, Linux (Ubuntu 22.04+ recommended)
- **Qt Version**: Qt 6.11 or higher
- **Compiler**: MSVC 2022 / Clang / GCC
- **RAM**: 8 GB minimum (16 GB recommended)

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/mokm-effector.git
cd mokm-effector
```
